### Android

Download `Run-Escape-<version>-android.apk` from Downloads at the top and open it on your phone.
The first time, Android asks whether your browser may install apps: allow it.

The app checks GitHub for updates when opened and offers to download a newer APK. Android shows
download progress in notifications, where you can cancel. Once it's downloaded, the app asks
whether to install it now or the next time you open it, as installing closes the game. The first
update may ask you to allow installs from Run Escape. If you're offline or the check fails, you
can keep playing the installed version.

Older copies without the updater need one manual update: install this APK over the one you have.
Don't uninstall the old one first: that deletes your progress. To keep a copy, use Export in
Settings.
